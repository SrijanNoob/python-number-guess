# python-number-guess# Number Guessing Game

A simple number guessing game built in Python.

## How to Play

1. Choose a difficulty level:
   - **Easy** – 10 attempts
   - **Medium** – 5 attempts
   - **Hard** – 3 attempts
2. Guess a number between 1 and 100.
3. Get hints on whether your guess is too high or too low.

## Requirements

- Python 3.x

## How to Run

```bash
Welcome to the Number Guessing Game!
Choose difficulty (easy/medium/hard): easy
You have 10 chances to guess the correct number.
Enter your guess: 50
Incorrect! The number is less than 50.
Enter your guess: 25
Congratulations! You guessed the correct number in 2 attempts.
